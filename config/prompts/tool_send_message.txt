在群里发出一条 QQ 消息。这是你向群里说话的唯一途径；不调用本工具，群里不会显示你输出的任何文字。调用成功后本次回复立即结束，同一轮里的其他工具调用不会执行，所以它必须放在所有检索、读网页和看图之后。

参数 content 是按发送顺序排列的消息段数组。只使用 schema 列出的类型，不要写 CQ 码，不要把 OneBot 的 type/data 字典塞进 text，也不要编造成员编号、发言编号、表情密钥、歌曲 ID 或 URL。

常用消息段：
- text：普通文字。只写群成员应该看到的内容，不写昵称前缀、时间、#N、⟦N⟧ 或其他系统标注。
- at：@ 一位成员。member 必须取自本次提示中该成员名字后的 ⟦N⟧。at 可以出现在 content 的任意位置，也可以重复；不要在相邻 text 里再写一次「@名字」。一次消息最多 5 个 at。
- reply：引用一条发言。line 必须取自本次提示中该行开头的 #N。一条消息最多一个 reply；通常放在 content 开头。

纯参数特殊段：
- face：QQ 系统表情。id 只从下面的固定目录中选择；没有合适的就用 text 表达，不要猜目录外的 ID。
  {{FACE_CATALOG}}
- dice、rps：分别发送随机骰子和猜拳表情，data 为空对象。
- contact_member：推荐一位成员，member 仍使用名字后的 ⟦N⟧。
- contact_group：推荐当前群，data 为空对象。
- music：发送平台歌曲卡片，platform 取 qq、163、kugou、kuwo、migu，id 是该平台的准确歌曲 ID。
- music_custom：发送自定义音乐卡片；url、audio、image 必须是明确给出的 http/https 地址，title 必填，singer 可省略。不要凭空生成地址。
- json：发送 QQ JSON 卡片，payload 是 JSON 对象。只在对方明确要求且已有可靠 payload 时使用；不要用它仿冒系统通知、身份、付款、登录或官方页面。

普通回答示例：刚收到的消息是 #18，发送者是成员编号 ⟦3⟧：
{"content":[{"type":"reply","data":{"line":18}},{"type":"at","data":{"member":3}},{"type":"text","data":{"text":"可以，晚上发你。"}}]}

在句中 @ 的示例：要表达「我问过成员甲，请成员编号 ⟦4⟧ 再确认」：
{"content":[{"type":"text","data":{"text":"我问过成员甲，请"}},{"type":"at","data":{"member":4}},{"type":"text","data":{"text":"再确认一下。"}}]}

发送骰子的示例：
{"content":[{"type":"text","data":{"text":"那就掷一次："}},{"type":"dice","data":{}}]}

如果工具结果说消息段、成员编号或发言编号无效，说明整条消息没有发出。修正参数后重新调用，不要假定无效部分已经被悄悄删除。
